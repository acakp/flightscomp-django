# Настройка API Яндекс Карт

Для отображения карт на сайте (карта офиса и карты маршрутов на странице предложений) мы используем JS API Яндекс Карт.

Чтобы карты работали без предупреждений и ошибок (и лимитов для песочницы), вам необходимо получить бесплатный API-ключ в Кабинете разработчика Яндекса и добавить его в ваш файл `.env`.

## Инструкция по получению ключа:
1. Перейдите в **Кабинет разработчика Яндекса**: https://developer.tech.yandex.ru/
2. Войдите под своим аккаунтом Яндекса.
3. Нажмите кнопку **"Подключить API"**.
4. В списке выберите **"JavaScript API и HTTP Геокодер"** (именно он нужен для отображения карт и поиска координат по названиям городов).
5. Заполните необходимую анкету (если спросят — укажите, что это учебный/некоммерческий проект).
6. В разделе "Ключи" скопируйте ваш новый сгенерированный API-ключ (он выглядит как длинная строка с дефисами).
7. Откройте файл `flightscompany/.env` в редакторе кода.
8. Вставьте полученный ключ в переменную `YANDEX_MAPS_API_KEY`:

```env
# ... ваши остальные настройки ...

# Yandex Maps
YANDEX_MAPS_API_KEY=ваш-скопированный-ключ-сюда
```

9. Перезапустите сервер разработки Django (`python manage.py runserver`).

Теперь карты в футере (Наш офис) и на страницах предложений будут работать корректно, используя ваш собственный API-ключ Яндекса.
