 Настройка отправки почты (Сброс пароля)

Для того чтобы функция сброса пароля (отправка писем с ссылкой для сброса) заработала, вам необходимо настроить реальный SMTP-сервер в файле `.env`. 

Код проекта уже настроен для чтения следующих переменных из файла `.env` (папка `flightscompany/`):
* `EMAIL_HOST` (по умолчанию `smtp.yandex.ru`)
* `EMAIL_PORT` (по умолчанию `465`)
* `EMAIL_HOST_USER`
* `EMAIL_HOST_PASSWORD`
* `EMAIL_USE_SSL` (по умолчанию `True`)

## Инструкция по настройке для Яндекс Почты (согласно методичке)

1. Перейдите в свой Яндекс ID: https://id.yandex.ru/security/app-passwords
2. Выберите **"Безопасность"** -> **"Пароли приложений"** (если раздел скрыт, перейдите в "Доступы" -> "Пароли приложений").
3. Создайте новый пароль: выберите тип приложения **"Почта"**, введите любое название (например, `Django Flights`), после чего Яндекс сгенерирует пароль (обычно он выглядит как набор букв, например `bnufhkwcripaunvu`).
4. **Обязательно скопируйте этот пароль** (он показывается только один раз).
5. В вашем аккаунте почты Яндекс перейдите в **Все настройки** -> **Почтовые программы** и убедитесь, что стоят галочки:
   * "С сервера imap.yandex.ru по протоколу IMAP" (с опцией "Пароли приложений и OAuth-токены")
6. Откройте файл `flightscompany/.env` в редакторе кода.
7. Заполните значения:
   ```env
   EMAIL_HOST=smtp.yandex.ru
   EMAIL_PORT=465
   EMAIL_HOST_USER=ваш_реальный_email@yandex.ru
   EMAIL_HOST_PASSWORD=скопированный_пароль_приложения
   EMAIL_USE_SSL=True
   ```
8. Перезапустите сервер Django, если он был запущен (`python manage.py runserver`).
9. Попробуйте сбросить пароль для пользователя. Письмо должно успешно прийти на указанную почту.

## Инструкция по настройке для Google (Gmail)

Если вы решите использовать Google (как предложено в методичке в качестве домашнего задания):
1. Перейдите в настройки аккаунта Google: https://myaccount.google.com/security
2. Убедитесь, что у вас включена **Двухэтапная аутентификация**.
3. В разделе двухэтапной аутентификации найдите внизу **"Пароли приложений"** (App passwords).
4. Создайте новый пароль (выберите "Почта" и ваше устройство или укажите "Другое" -> "Django").
5. Скопируйте сгенерированный 16-значный пароль (без пробелов).
6. В файле `flightscompany/.env` укажите следующие настройки:
   ```env
   EMAIL_HOST=smtp.gmail.com
   EMAIL_PORT=465
   EMAIL_HOST_USER=ваш_реальный_email@gmail.com
   EMAIL_HOST_PASSWORD=скопированный_пароль_приложения_без_пробелов
   EMAIL_USE_SSL=True
   ```
7. Перезапустите сервер Django.

После этих шагов функционал восстановления пароля будет работать на 100%.
