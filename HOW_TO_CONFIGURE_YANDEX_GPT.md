# Настройка API ЯндексGPT

Для работы чат-бота на сайте мы используем YandexGPT API.

Чтобы бот мог отвечать на вопросы, вам необходимо получить API-ключ и идентификатор каталога в Яндекс Cloud и добавить их в файл `.env`.

## Инструкция по получению ключей:

1. Перейдите в **Яндекс Cloud**: https://console.yandex.cloud/
2. Войдите под своим аккаунтом Яндекса. Если вы здесь впервые, создайте платежный аккаунт (для Yandex GPT дают стартовый грант или бесплатные лимиты).
3. Создайте новый каталог (Folder) или выберите существующий (например, `default`).
4. Скопируйте **Идентификатор каталога** (Folder ID). Он выглядит как набор символов, например `b1g...`.
5. В левом меню перейдите в раздел **Сервисные аккаунты**.
6. Создайте новый сервисный аккаунт, дайте ему имя и назначьте роль `ai.languageModels.user` на ваш каталог.
7. После создания нажмите на этот сервисный аккаунт и перейдите на вкладку **API-ключи**.
8. Нажмите **Создать новый ключ**, укажите описание и создайте ключ.
9. **Обязательно скопируйте API-ключ** (он показывается только один раз).
10. Откройте файл `flightscompany/.env` в редакторе кода.
11. Вставьте скопированные идентификатор каталога и API-ключ в соответствующие переменные:

```env
# ... ваши остальные настройки ...

# Yandex GPT
YANDEX_GPT_API_KEY=ваш-скопированный-api-ключ 
YANDEX_FOLDER_ID=ваш-идентификатор-каталога
```

12. Перезапустите сервер разработки Django (`python manage.py runserver`).

После этого чат-бот в углу экрана сайта сможет отвечать на ваши вопросы с помощью нейросети ЯндексGPT.
